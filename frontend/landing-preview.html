01 Signal flow

Six stages.
One clean chart.

Every upload runs the full DSP + neural pipeline — no cloud black box, no manual mapping. Each stage streams its progress live over Server-Sent Events.

Pipeline integrity 192 PPQ grid
24-tick sustain margin
35–40 ms chord fusion
DSP-STEM Stage 01

Demucs v4 stem separation

Meta htdemucs · hybrid transformer

Isolates the lead guitar from full stereo masters before pitch extraction — stripping drums, vocals and sub-bass bleed.

44.1 / 48 kHz FP32 tensor → isolated guitar stem + mono fallback
DSP-SYNC Stage 02

Tempo & beat tracking

BeatNet & Librosa · 192 PPQ grid

Extracts dynamic tempo maps, beat positions and meter signatures, then converts seconds into 192-pulse-per-quarter ticks.

Milli-BPM serialization · 120.0 BPM → B 120000
AI-MIDI Stage 03

Polyphonic transcription

Spotify Basic Pitch · CNN audio-to-MIDI

Predicts note events — pitch 0–127, onset, offset and confidence amplitude — directly from the isolated guitar stem.

NoteEvent(start, end, pitch, amplitude[0.0–1.0])
DSP-FILT Stage 04

Harmonic suppression

Spectral & octave artifact filter

Removes high-gain distortion harmonics — octave +12 st and fifth +19 st — that would otherwise become false chords.

Suppresses overtone spikes within 25 ms of the fundamental onset
MAP-5FRT Stage 05

Game design mapping

Tessitura projection · HOPO heuristics

Fuses string-roll micro-delays into chords, snaps onsets to valid subdivisions, and projects pitch onto the five frets.

1/4 (192) · 1/8 (96) · 1/12 (64) · 1/16 (48) · 1/24 (32) · 1/32 (24)
PKG-BIN Stage 06

Chart & package writing

notes.chart · song.ini · song.ogg

Serializes strict Clone Hero text charts and little-endian .sng containers, then packages a drop-in song folder.

UTF-8 notes.chart + .sng v1 + ready-to-play ZIP archive

DSP-FILT / overtone guard Before mapping

Distortion harmonics, removed.

High-gain amps ring at +12 and +19 semitones. The spectral filter identifies and deletes those artifacts before a single fret is assigned.

05 Deploy & deliver

The public demo is free forever. Want your own GPU, your own queue, your own storage? The whole stack is containerized.

Self-host in one command

Your metal. Your queue.

FastAPI + React 19 + PyTorch/Demucs in a single Compose stack. GPU if you have it, CPU fallback if you don't.

bash — music2chart 
# clone + launch the full stack
$ git clone https://github.com/Adiells/music2chart.git
$ cd music2chart
$ docker compose up --build -d

✔ api        http://localhost:8000
✔ frontend   http://localhost:5173
✔ demucs     htdemucs loaded
$ open http://localhost:5173 # drop a song
